# PickTV

PickTV 以 [FongMi/TV](https://github.com/FongMi/TV) 為基礎開發。

此儲存庫主要保留專案來源與原始程式碼，方便後續比對及持續開發。這裡存放的是原始開源程式碼，並非目前實際使用、維護或對外發佈的修改版本。

目前曾進行的調整以部分 UI 版面及少量相容性修改為主，整體仍以原專案為基礎。

感謝 [FongMi/TV](https://github.com/FongMi/TV) 原作者及所有貢獻者。
